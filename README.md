# HSP-polymer-solvents-MW
Script for optimizing solvent mixtures (pure, binary, and ternary) HSPs to target HSPs

Expand the library with known Hansen Solubility Parameters of solvents if needed. 

The current target solvent is dichloromethane (DCM), but it can be edited to the desired solvent HSP values


Code also produces a 2D projection of optimal solvent mixtures.
